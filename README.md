# Color Sorting Project 🤖

## About the Project
This project focuses on color detection and sorting using Python, computer vision, and a robotic arm. It includes notebooks for basic arm movements, HSV color calibration, and color sorting.

## Technologies Used
- Python
- OpenCV
- Jupyter Notebook
- HSV Color Space
- DOFBOT Robotic Arm

## Project Files
- `Basic Movements.ipynb` – Demonstrates basic robotic arm movements.
- `HSV_calibration.ipynb` – Used to calibrate HSV values for color detection.
- `Color Sorting.ipynb` – Contains the color sorting implementation.
- `HSV_config.txt` – Stores HSV threshold values for different colors.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries and supporting robotic arm modules.
3. Connect the camera and compatible robotic arm.
4. Open the notebooks using Jupyter Notebook.
5. Run the notebooks to test arm movements, calibrate colors, and perform color sorting.

## Applications
- Computer vision
- Robotics
- Automated color sorting
- Industrial automation learning
